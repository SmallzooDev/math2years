# Basic Mathematics

Serge Lang 이 쓴 책이다. 미적분과 선형대수로 넘어가기 전에 필요한 기초 수학을 다룬다. 출판사는 이 책을 "a text in basic mathematics with multiple uses" 라고 소개한다.

## 출처

- Serge Lang, *Basic Mathematics*, Springer New York, 1988
- ISBN 978-0-387-96787-5, 496쪽
- https://link.springer.com/book/9780387967875
